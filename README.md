# java-lotto-precourse

## 프로그램 설명

로또 구입, 로또 발행, 당첨 과정을 시뮬레이션하는 프로젝트입니다.

### 프로그램 흐름

1. 로또 구입 금액을 입력합니다. 구입 금액은 1,000원 단위여야 합니다. 로또는 하나에 1,000원입니다.
2. 구입한 개수만큼 로또를 발행하고, 로또 번호를 출력합니다. 하나의 로또 안에서 번호는 오름차순 정렬입니다.
3. 당첨 번호를 입력합니다.
4. 보너스 번호를 입력합니다.
5. 당첨 통계를 출력합니다. 수익률은 소수점 둘쨰 자리에서 반올림한 값입니다.

### 입출력 예시

```text
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

### 오류

값을 잘못 입력한 경우 `[ERROR]`로 시작하는 오류 메시지를 출력하며, 다시 입력을 요구합니다.

예시는 다음과 같습니다.

```text
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

## 구현 기능 목록
1. 사용자 입력 + 예외 처리
  - [x] 구입 금액 입력: 1000원 단위의 금액을 입력받는다.
  - [x] 당첨 번호 입력: 콤마로 분리되는 중복되지 않는 1-45 사이의 숫자 6개를 입력받는다.
  - [x] 보너스 번호 입력: 당첨 번호와 중복되지 않는 1-45 사이의 숫자 1개를 입력받는다.

2. 로또 발행
  - [x] 로또 발행: ~~입력한 금액~~ N개의 로또를 발행한다.

2. 로또 검증
  - [x] 로또의 번호 중복 검증: 로또 생성 시 로또 번호에 중복이 있다면 예외를 던진다.
  
3. 로또 출력
  - [x] 로또의 번호를 오름차순으로 정렬하여 출력한다.

4. 결과 출력
  - [x] 당첨 확인: 주어진 규칙에 따라 당첨 여부를 확인하고 결과를 반환한다.
  - [x] 수익률 계산: 로또 개수와 당첨 결과를 받아 소수점 둘째 자리에서 반올림한 수익률을 계산한다.
  
5. 전체 흐름 제어
  - [x] 의존관계 연결 및 흐름 제어: 실행에 필요한 의존관계를 연결하고, 실행 흐름을 생성한다.
